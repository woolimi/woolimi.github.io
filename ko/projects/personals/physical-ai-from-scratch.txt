Physical AI 를 이루는 아이디어를 하나씩 직접 구현하며 따라가는 독학 커리큘럼입니다. 과제 37개가 선수 관계로 이어져 있고, 이 관계를 Ecole 42 의 holygraph 처럼 가운데에서 바깥으로 퍼지는 지도로 그렸습니다. 위 지도는 제 학습 리포의 진행 기록을 그대로 읽어 칠한 것이라서, 원을 누르면 과제 설명과 함께 평가 결과와 구현 코드 링크가 열립니다.

## 과제 구성

| branch | 다루는 것 |
| --- | --- |
| Foundations | numpy, perceptron, backpropagation, PyTorch 학습 루프 |
| Language | BPE tokenizer, Transformer, GPT-2 |
| Vision | CNN, ResNet, ViT, CLIP |
| Generative Models | VAE, DDPM, flow matching |
| Imitation Learning | behavior cloning, DAgger, RT-1, Diffusion Policy, ACT, 실물 로봇 |
| Reinforcement Learning | bandit·MDP, DQN·SAC, policy gradient, PPO, sim-to-real 보행 |
| Robotics | 좌표 변환, kinematics, PID, MuJoCo, 카메라, pick-and-place, teleoperation 데이터 |
| VLA | RT-2 → OpenVLA, π0 |
| Frontier | world model, VLA 의 RL fine-tuning |

과제마다 배경과 핵심 수식, 직접 짤 부분, 시작 코드의 모양, 평가 기준, 구두 질문이 같은 순서로 들어 있습니다. 평가 기준은 대부분 torchvision·Hugging Face·LeRobot·CleanRL 같은 공식 구현과 출력을 비교하는 방식입니다.

## 평가 방식

과제는 Claude Code 의 평가 skill 로 Ecole 42 의 defense 처럼 평가받습니다.

- **규칙 검사**: 직접 짜야 하는 부분을 library 호출로 대신하지 않았는지 확인
- **평가 기준 검사**: 제출 코드를 실행해 항목별로 판정하고, GPU 학습이나 실물 로봇 실험은 커밋된 log·결과 표·영상으로 판정
- **구두 평가**: 과제의 질문과 제출 코드에 관한 질문에 코드를 보지 않고 답변

필수 기준을 모두 통과하고 구두 평가에서 틀리거나 설명하지 못한 답이 없어야 완료로 기록되고, 회차별 평가 결과는 과제 폴더의 `EVALUATION.md` 에 남습니다.
